# Contributing

1. Open an issue: a bug (the agent did the wrong thing) or an idea.
2. Pull requests: one change per PR. Keep `SKILL.md` tight; details belong in `templates/`.
3. Check the frontmatter: `name: tomviber` matches the folder name; `description` says *when* to use the skill.
4. `templates/AGENTS.md` stays at 70 lines max, and its first line is the marker `<!-- tomviber v1 -->`.
5. Instructions are in English. User-facing canned phrases come in both EN and RU — keep them in sync.
6. Update `CHANGELOG.md`.

Plain words beat jargon — the audience is people who don't read code.
