# Как помочь

1. Откройте issue: баг (агент сделал не то) или идея.
2. Для PR: одна правка — один PR; `SKILL.md` держите коротким, детали — в `templates/`.
3. Проверьте frontmatter: `name: vibe-architect` совпадает с именем папки, `description` описывает, *когда* запускать.
4. `templates/AGENTS.md` — не длиннее 60 строк.
5. Обновите `CHANGELOG.md`.

Пишите по-русски; простые слова важнее терминов.
